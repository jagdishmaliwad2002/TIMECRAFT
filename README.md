# TIMECRAFT - Luxury Watches Website

A modern, premium, and fully responsive landing page for a luxury watch brand. This project features a sophisticated design with clean typography, elegant layout, and high-performance optimized images.

## 👨‍💻 Created By
**Jagdish Maliwad**

## ✨ Features

- **Sticky Navigation:** Includes a top announcement bar and a clean, modern navigation menu.
- **Hero Section:** Stunning full-width background image with an elegant overlay and call-to-action buttons.
- **USP Bar:** Highlights key selling points (Free Shipping, Easy Returns, Secure Payment, Customer Support).
- **Responsive Grid Layouts:** Beautifully designed grids for "Shop By Category" and "Best Sellers" that adapt perfectly to all screen sizes.
- **Promotional Banners:** Eye-catching sections for Limited Edition watches and the "Timecraft Club" membership.
- **Newsletter Subscription:** Clean and functional email signup form.
- **Comprehensive Footer:** Includes quick links, trust badges, social media icons, and payment gateways.
- **Fully Responsive:** Optimized for Desktop, Tablet, and Mobile devices using CSS Grid, Flexbox, and Media Queries.

## 🛠️ Technologies Used

- **HTML5:** Semantic and accessible structure.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and smooth transitions.
- **FontAwesome:** Premium icon library for UI elements.
- **Google Fonts:** 
  - `Playfair Display` (Serif) for elegant headings.
  - `Inter` (Sans-serif) for clean body text.

## ⚡ Performance Optimizations

To ensure fast loading times and a smooth user experience, the following optimizations were implemented:
- **WebP Image Format:** All images are requested in WebP format via URL parameters (`fm=webp`) to significantly reduce file sizes.
- **Lazy Loading:** Added `loading="lazy"` to product and category images so they only load when the user scrolls down.
- **Reduced Image Resolution:** Hero image is capped at `w=1200`, and product images at `w=300` to prevent loading unnecessarily large files.
- **Fallback Background:** The hero section has a dark fallback background color to ensure text remains visible even if the image takes a moment to load.

## 🚀 How to Use

1. Clone or download this repository to your local machine.
2. Ensure you have an internet connection (to load the Google Fonts, FontAwesome icons, and Unsplash images).
3. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
4. That's it! No build tools or server required.
